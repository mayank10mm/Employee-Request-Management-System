Employee Request Lifecycle

Intake → ID → Categorize → Assign → OPEN → SLA check → ACTIVE → Resolve → FINALIZED → Archive. 

flowchart TD
  subgraph intake ["1. Omni-channel Intake"]
    portal["Web Portal"]
    email["Email"]
    whatsapp["WhatsApp"]
    sms["SMS"]
    unified["Unified API"]
    portal --> unified
    email --> unified
    whatsapp --> unified
    sms --> unified
  end

  idGen["2. Generate EMP-xxxxx ID + PostgreSQL + audit"]
  categorize["3. Auto Categorization HR / IT / Payroll / Ops / Other"]
  assign["4. Assign least-loaded agent"]
  openNode["5. Status OPEN"]
  slaCheck{"6. SLA breached?"}
  escalate["Escalate to Department Lead"]
  activeNode["7. Status ACTIVE"]
  resolve["8. Resolve issue"]
  finalized["9. Status FINALIZED"]
  archive["10. Archive for reporting"]

  unified --> idGen --> categorize --> assign --> openNode --> slaCheck
  slaCheck -->|Yes| escalate --> activeNode
  slaCheck -->|No| activeNode
  activeNode --> resolve --> finalized --> archive
